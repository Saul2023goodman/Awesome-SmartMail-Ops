# v1.42 上传后分类核验工作区

本版把上传后的核验从“纵向目录列表 + 点击检查后再展开诊断”重构为一个连续的分类工作区。

## 这一阶段真正要完成什么

上传完成后，用户并不需要理解解析器、置信度算法或字段探测过程；用户只需要快速确认三件事：

1. 系统把每个文件当成了什么；
2. 明显分错的文件能否立即改正；
3. 待确认文件能否快速看内容并决定用途。

因此界面改为同一视野中的 **目录定位 → 文件核验 → 就地预览 → 重新分类 → 继续**，不再把“检查”设计成一次跳转或二级流程。

## UI 与交互变化

- 三栏工作区：左侧目录，中间文件核验，右侧当前文件预览。
- 顶部五类概览：邮件、总名单、附件、待确认、暂不使用；点击可快速筛选。
- 中间分类投放区：文件可通过拖拽手柄拖入目标类别。
- 文件行取消独立“检查”动作；点击文件本身即在右侧打开核验，不离开当前列表。
- 右侧只显示用户需要判断的内容：当前分类、为什么这样分、内容预览、快速改分类。
- 邮件显示收件人 / 主题 / 正文摘要；名单显示少量表格预览；附件显示用途说明。
- 数字置信度、字段识别细节等技术信息不再占据主界面；只有读取内容确实异常时，才可展开“进一步调整”。
- 支持“只看待确认”、文件名搜索、目录筛选、顶部分类筛选和“下一个待确认”。
- 参考总名单 / 附件补充收进左侧折叠区，作为分类完成后的可选增强，不抢占主任务。
- “返回上传”只关闭核验工作区，已做的分类修正会保留；之后可继续添加资料再回来核验。

## 业务原则

**核验不是诊断。** 主界面回答“这个文件是什么、我要不要改”；技术原因只在必要时展开。

**纠错发生在错误出现的地方。** 自动分类结果和人工修正共享同一列表，不再让用户记住文件后去另一模块找入口。

**减少上下文切换。** 点击文件不会跳走，右侧预览与中间列表保持同时可见；处理完一个待确认文件可直接进入下一个。

**拖拽是快捷方式，不是唯一方式。** 同时保留文件行分类选择和右侧分类按钮，兼顾效率、可发现性与可访问性。
