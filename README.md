# NetEase Mail Draft Assistant v1.15.0

网易邮箱网页版草稿工作台。目标很简单：把一批邮件资料整理成可检查、可安排、可创建的网易草稿。只保存草稿，不自动发送。

## 现在怎么用

批量草稿只保留四个连续动作：

1. **添加资料**：选择文件、文件夹，或直接粘贴内容。
2. **检查邮件**：查看解析预览，只修改需要处理的邮件，也可以抽查全部邮件。
3. **选择与安排**：选择本次要创建的邮件；需要时展开自动安排时间。
4. **创建草稿**：确认选择后统一创建网易草稿。

一级工作区只保留：**批量草稿 / 单封草稿 / 联系人**。

## v1.15.0 的主要变化

### 解析预览回到批量流程

“逐条确认”不再是独立工作区。解析预览紧跟导入结果出现，用来检查收件人、主题和正文。检查完成后继续向下选择邮件，不需要离开当前批次。

### 批量填写不再单独占区域

只有选中邮件后才出现批量操作。需要补主题时，可以直接给所选邮件补充空白主题，并一次保存所选修改；已有主题不会被覆盖。

### 选择和排时间合并

选择邮件与安排时间属于同一次批次决策，因此放在同一个“选择与安排”区域。自动安排时间默认收起，需要时再展开。

### 页面更紧凑

- 右侧只保留一条批量流程导航。
- 邮件列表减少不必要列，附件等信息合并进状态。
- 解析预览只显示收件人、主题、正文这些真正需要检查的内容。
- 可选名单、附件、字段调整等低频功能默认收起。
- 最后的“创建草稿”不再悬浮覆盖页面内容。
- 窄窗口下流程导航自动缩成编号或横向步骤，避免挤压邮件正文。

## 联系人

联系人页面负责联系记录与邮箱同步。日常主操作只保留“同步邮箱”；重建记录等维护操作放在折叠选项中。

## 安全边界

- 只创建并保存草稿，不自动发送。
- 每封草稿确认保存成功后才继续下一封。
- 批量执行遇到错误立即停止，避免串稿。
