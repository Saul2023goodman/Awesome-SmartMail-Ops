# 网易邮箱草稿助手 v0.1.1

用于网易 163 邮箱网页版的 Chrome MV3 插件。

## 当前功能

- 自动打开“写信”页
- 填写收件人
- 填写主题
- 填写正文（进入网易编辑器 iframe）
- 选择并注入一个或多个附件
- 打开“更多发送选项”并启用定时发送
- 设置年 / 月 / 日 / 时 / 分
- 可选自动点击“存草稿”
- **不会自动发送邮件**

## v0.1.1 修复

1. 修复顶部按钮视觉文本为“写 信”时无法识别“写信”的问题。
2. 打开写信不再以 DOM 按钮为唯一入口：优先通过网易页面自身 `window.Interface.compose()` 进入 Compose，DOM 语义定位仅作回退。
3. Compose 状态识别增加主题/收件人输入框结构兜底。
4. “更多发送选项”“定时发送”“存草稿”的文字定位统一忽略布局空格、NBSP 与零宽字符。
5. 如果以后仍无法定位写信入口，错误状态会附带可见导航元素摘要，便于快速适配。

## 安装 / 升级

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 如果已经安装 v0.1.0，可删除旧版本后选择“加载已解压的扩展程序”；也可用新文件夹重新加载。
5. 选择 `netease-mail-draft-assistant-v0.1.1` 文件夹。
6. 回到网易邮箱并刷新页面。

建议使用测试邮箱验证附件、收件人提交和定时设置。
