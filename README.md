# NetEase Mail Draft Assistant v0.9.0

本版本在 v0.8.0 的统一分类、批量草稿、附件、全文检索和联系人历史基础上，扩展“邮箱历史同步”。

## 新增：更大的读取范围

联系人页的邮箱历史读取范围改为：

- 最近 50 封
- 最近 100 封
- 最近 200 封
- 最近 500 封
- 最近 1000 封
- 最近 2000 封
- 全部

超过 200 封时，后台会以 200 封左右的小页进行自适应分页，而不是依赖一次超大 `limit`。分页会优先尝试网易列表接口的游标方式，并在运行环境里自动判断可用分页模式。

“全部”设置了 10,000 封保护上限，避免极端邮箱在一次同步中长时间占用页面。如果接口无法继续分页，UI 会明确显示“部分覆盖”和停止原因，不会假装已经读取完整。

联系人表格显示上限从 300 个提高到 1000 个；更多联系人可通过搜索和统一分类筛选缩小范围。

## 新增：读取草稿箱

联系人页的“邮箱历史同步”现在包含两种数据源：

### 已发送

- 使用网易 `mbox:listMessages`，文件夹 `fid: 3`
- 读取收件人、主题、时间和发送状态
- 成功发送记录可推动联系人阶段 `未联系 -> 已发送`
- 重复扫描按邮件 ID 去重

### 草稿箱

- 使用网易 `mbox:listMessages`，文件夹 `fid: 2`
- 读取草稿收件人、主题和保存时间
- 建立 `联系人 <-> 草稿` 关联
- **不会**因为存在草稿就将联系人改为“已发送”
- 没有填写收件人的草稿会计入扫描结果，但不会强行建立联系人

如果本次读取完整覆盖整个草稿箱，插件会同步当前真实草稿状态：已经删除或已经发送、因此不再存在于草稿箱的旧草稿标记会被清理。如果只读取前 N 封，则不会贸然删除旧标记。

## 统一分类新增：有草稿

“有草稿”属于系统自动分类：

- 草稿箱同步后自动产生
- 当前联系人存在已识别草稿时显示
- 可直接在联系人分类筛选中使用，例如 `未联系;有草稿`
- 不能作为 Excel 普通任务分类手工伪造
- 不等价于“已发送”

## 联系人列表新增草稿信息

联系人表现在显示：

- 联系人
- 统一分类
- 已发送数量
- 当前已识别草稿数量
- 最后发送时间
- 最后草稿时间与草稿主题
- 最近发送主题

联系人搜索也会检索草稿主题。

## 联系人 CSV

导出字段增加：

- 当前草稿数
- 最后草稿时间
- 最后草稿主题

## 安全边界

插件继续只创建/管理草稿，不自动点击最终发送。
