# 网易邮箱草稿助手 v0.2.1

Chrome MV3 插件。只创建/保存草稿，不自动发送邮件。

## v0.2.1：批量草稿工作台

### 支持导入

- `.xlsx`（现代 Excel Open XML）
- `.csv`
- `.tsv`
- `.json`
- `.txt`（按分隔文本识别）

旧版二进制 `.xls` 暂不直接解析，请另存为 `.xlsx` 或 CSV。

### 自动识别流程

1. 扫描每个工作表前 20 行，寻找最像表头的行。
2. 自动选择字段识别得分最高的工作表。
3. 通过中英文同义词识别：编号、收件人、主题、正文、附件、定时时间、是否定时。
4. 显示字段映射，允许人工修改。
5. 生成逐行预检结果；附件缺失、同名冲突、无法解析的定时时间会阻止该行执行。
6. 批量执行固定为单线程逐封：新建 Compose → 填入 → 附件 → 定时 → 存草稿 → 下一封。

### 推荐表头

| 编号 | 收件人 | 主题 | 正文 | 附件 | 定时时间 |
|---|---|---|---|---|---|
| 001 | mail-test@example.com | 测试主题 | 正文 | 材料.pdf;附件2.docx | 2026-08-25 09:30 |

插件内置“下载 CSV 模板”。

## 附件识别方案

浏览器不能根据 Excel 中的 `C:\...` 路径静默读取本地文件，因此 v0.2.1 使用“文件池”方案：

1. 表格附件列写文件名或相对路径；多个附件用 `;`、`；`、`|` 或换行分隔。
2. 用户在插件中一次选择附件目录，或追加若干独立文件。
3. 插件建立本地 File 对象索引。
4. 优先按相对路径精确匹配；其次按唯一文件名匹配。
5. 找不到或出现同名歧义时，该行预检失败，不会静默漏附件。

例：`申请材料/CV.pdf;成绩单.pdf`

## 定时时间识别

支持：

- Excel 日期时间序列值
- `2026-08-25 09:30`
- `2026/08/25 09:30`
- `2026年8月25日 09:30`
- 可被浏览器标准 Date 解析的常见格式

如果网易分钟下拉框没有目标分钟，执行器仍会使用网易实际可选的最近值，并在运行记录中注明。

## 安装

1. 解压 ZIP。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 加载已解压的 `netease-mail-draft-assistant-v0.2.1` 文件夹。
5. 刷新已登录的网易 163 邮箱页面。
6. 点击右下角“草稿” → “批量”。

## 执行安全原则

- 不自动点击最终发送。
- 批量固定单线程，避免多个 Compose 页面状态串扰。
- 每封必须新建 Compose 实例；检测不到新实例时停止，避免覆盖上一封草稿。
- 导入预检错误默认阻止对应行执行。


## v0.2.1 修复

- 修复带 XML namespace 前缀的标准 XLSX（例如 `<x:sheet>` / `<x:row>` / `<x:c>`）被误判为“没有可读取的工作表”。
- Workbook、Relationships、SharedStrings、Worksheet 全部改为按 XML `localName` 读取，同时兼容有前缀和无前缀 OOXML。
- 增加 XLSX 工作表/关系解析诊断信息，方便后续定位第三方 Office/WPS 生成文件的兼容性问题。
