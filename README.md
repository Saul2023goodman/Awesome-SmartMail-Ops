# NetEase Mail Draft Assistant v1.13.0

网易邮箱网页版外联工作台。只创建并确认保存草稿，不自动发送。

## v1.13.0：业务工作台深层重构

本版不增加新的业务能力，而是把界面从“功能模块拼接”重构为“用户完成一次外联批次的连续工作台”。

### 新的信息架构

一级功能只保留三个：

1. **批量工作台**：准备邮件 → 必要核对 → 选择任务 → 安排时间 → 创建草稿。
2. **单封草稿**：处理不属于批次的临时单封邮件。
3. **联系人**：长期联系状态、跟进与邮箱同步。

原“导入与核对”和“批量创建”合并为一个批量工作台，流程指引只出现一次，用户不再跨页面完成同一批次。

### 减少重复与无意义入口

- 文件选择本身已支持 ZIP，因此移除独立的“打开 ZIP”主入口。
- “快速刷新 / 完整重建”不再作为两个同权日常操作：正常路径只显示“同步邮箱”，完整重建降级到“维护选项 → 重建联系人记录”。
- 任务选择区隐藏“取消当前筛选结果”这一低频且与“取消全部选择”高度重叠的入口，保留“选择筛选结果 / 取消全部选择”。
- 批量准备完成后不再“跳转到批量创建模块”，而是在同一页面确认准备状态并继续向下执行。

### 分层原则

- **默认层只呈现业务动作和业务结果**：来源、需要确认的问题、选择、时间、草稿结果。
- **复杂能力按需展开**：字段映射、来源结构、重建联系人记录等只在异常或维护时出现。
- **功能区按生命周期分离**：单次批次工作与长期联系人管理分开；单封临时任务与批量工作分开。

## 批量业务流程

1. **准备邮件**：选择文件、文件夹或粘贴内容；可选导入总套磁名单；系统自动整理。
2. **必要核对**：只处理缺失、冲突或附件匹配失败的邮件。
3. **选择任务**：勾选本次真正要创建的邮件，可搜索、筛选和批量标记。
4. **安排时间**：默认支持“同校每 7 天最多 1 位”等规则，并保留已有时间。
5. **创建草稿**：逐封写入网易写信页并确认“存草稿”成功后才继续。

联系人不是每个批次的必经步骤，而是独立的长期状态工作区。
