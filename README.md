# NetEase Mail Draft Assistant v1.17.0

网易邮箱网页版草稿辅助插件。核心流程保持为：**添加资料 → 检查邮件 → 选择与安排 → 创建草稿**。插件只保存草稿，不自动发送。

## v1.17.0：完整阅读与顺势操作

- **检查邮件完整显示**：取消“原文 / 邮件内容”两个面板的独立限高滚动。邮件列表保留独立导航滚动，原文和编辑内容改由工作台主滚动承载。
- **正文自动长高**：编辑正文随内容自动扩展，不再把长邮件压进 145px 左右的小文本框。
- **自动安排时间默认展开**：进入“选择与安排”后直接看到开始时间、同校每轮上限、间隔和保留已有时间，不再先点一次“展开”。用户仍可自行收起。
- **主题顺势补齐**：当一封原本缺主题的邮件被填写主题后，如果同批还有其他空白主题，会在主题框下就地询问是否一键填写；只补空白，不覆盖已有主题。
- **编辑先保留、确认再放行**：切换邮件或收起预览前会保留当前修改；“保存”改为“确认本封”，“保存并下一封”改为“确认并下一封”，避免把“防丢编辑”和“确认解析正确”混成一个动作。
- **批量区继续减负**：移除独立的批量主题输入条；多选区只负责批量确认，主题批量化发生在用户真正填写主题的地方。

## 业务原则

1. **完整内容不塞进多层滚动容器。** 邮件是需要连续阅读的核心内容，主页面负责滚动；只有邮件列表这种导航集合保留独立滚动。
2. **高频必经选项默认可见。** 自动排程是“选择与安排”的主要任务，因此默认展开；低频高级设置继续按需隐藏。
3. **在动作发生处预测下一步。** 用户刚填写一个空白主题时，系统已经拥有足够上下文判断“其他空白主题是否可能需要同样内容”，此时询问比让用户主动寻找批量功能更省操作。
4. **建议不能偷偷改数据。** 一键主题只有用户明确点击后才应用，并且永远不覆盖非空主题。

## 文件

- `content.js`：界面与网易邮箱交互
- `content.css`：工作台样式与响应式布局
- `importer.js` / `import-core.js` / `mail-recognizer.js`：导入与解析
- `scheduler.js`：自动排程
- `contacts.js`：联系人状态
- `PERFORMANCE-REFACTOR.md`：v1.16 性能结构说明
- `UX-REFACTOR-v1.17.md`：本轮交互重构说明

## 安装

1. 解压插件目录。
2. Chrome/Edge 打开扩展管理页并启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向该目录。
4. 打开网易邮箱网页版使用。
