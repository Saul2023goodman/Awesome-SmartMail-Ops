# NetEase Mail Draft Assistant v0.4.0

面向网易邮箱 163 Webmail 的本地 Chrome MV3 助手。

## v0.4.0 新增：已发送读取 + 联系人状态库

插件现在有三个工作区：

1. **单封**：填写收件人、主题、正文、附件、定时信息并保存草稿。
2. **批量**：导入 XLSX / CSV / TSV / JSON，智能识别字段、匹配附件、顺序创建草稿。
3. **联系人**：读取网易“已发送”，建立联系人历史并手工维护联系状态。

### 读取已发送的机制

不使用页面滚动/OCR，也不依赖已发送列表的动态 DOM ID。

网易自己的前端代码已经使用 `mbox:listMessages` + `fid:3` 读取已发送邮件，并通过每封邮件的 `to` 字段生成最近联系人。v0.4.0 按同一页面内部数据接口读取最近 50 / 100 / 200 封已发送邮件。

读取字段仅用于本地联系人状态：

- 邮件 ID
- 主题
- 收件人邮箱 / 名称
- 发送时间（若返回）
- 发送状态（用于排除明确发送失败记录）

插件不会读取邮件正文，也不会把联系人数据上传到第三方。

### 联系人状态

内置状态：

- 未联系
- 已发送
- 已回复
- 待跟进
- 暂停
- 不再联系

规则：

- 扫描到成功的已发送记录：新联系人自动成为“已发送”。
- 原状态为“未联系”：自动升级为“已发送”。
- 手工状态（例如“已回复”“待跟进”）不会被后续扫描覆盖。
- 明确标记为发送失败的已发送记录不会用于自动升级联系人状态。

每个联系人还保存：

- 已识别发送次数
- 最后发送时间
- 最近发送主题
- 最多 50 条本地发送摘要，用于去重和状态依据

重复扫描同一批已发送邮件不会重复累计发送次数。

### 与批量功能联动

批量预检新增 **“联系人状态”** 列，可以在建草稿前看到：

- 未联系
- 已发送
- 已回复
- 待跟进
- 暂停
- 不再联系

联系人页提供 **“同步当前批量名单”**：把当前导入表里的收件邮箱加入联系人库。新邮箱默认为“未联系”，已有状态不会被覆盖。

这使插件可以在后续版本继续扩展：重复发送提醒、按状态过滤批量任务、待跟进提醒等。

### 本地与账号隔离

联系人状态保存在 `chrome.storage.local`，并按当前网易邮箱账号 UID 分开存储。切换不同 163 邮箱账号不会共用同一联系人状态表。

联系人页支持导出 CSV，字段：

`邮箱 / 姓名 / 状态 / 已识别发送次数 / 最后发送时间 / 最后主题`

## 附件机制（v0.3.0 保留）

- 公共附件：每一封都添加，例如统一 CV、成绩单。
- 专属附件：一次多选或拖入，按表格附件名匹配。
- 附件总目录：可扫描目录并按相对路径匹配。
- 同名或缺失附件：执行前人工指定，不静默猜测。
- 支持 `file.pdf` 对 `file(1).pdf` 这类浏览器下载副本名的低优先级匹配。

## 安装

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 选择“加载已解压的扩展程序”。
5. 选择 `netease-mail-draft-assistant-v0.4.0` 文件夹。
6. 刷新已登录的网易邮箱网页。

## 推荐测试

### 联系人功能

1. 打开插件 → 联系人。
2. 选择“最近 50 封”。
3. 点击“读取已发送”。
4. 确认联系人、发送次数、最近主题出现。
5. 随机将一名联系人改成“待跟进”。
6. 再次“读取已发送”，确认手工状态仍保持“待跟进”。

### 批量联动

1. 导入一份包含已联系邮箱和新邮箱的批量表。
2. 联系人页点击“同步当前批量名单”。
3. 回到批量页，检查“联系人状态”列是否正确区分。

## 边界

- 当前“读取已发送”最多读取最近 200 封，这是网易自身“最近联系人”逻辑使用的同级规模；尚未实现整个邮箱历史的分页遍历。
- “已回复”目前是手工状态。插件尚未扫描收件箱/会话来自动判定回复。
- 插件仍然**不会自动发送邮件**；批量模块只创建并保存草稿。
