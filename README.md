# NetEase Mail Draft Assistant v0.8.0

本版重点：发送列表的信息模型和执行范围重新整理。

## 1. 为什么旧“执行范围”下拉不清楚

旧版把“全部纳入发送 / 仅当前筛选结果”放在开始按钮旁，但没有说明它控制的是**本次执行集合**，而列表里又同时存在“发送勾选”和“分类筛选”，形成三套相似概念。v0.8.0 改成带标题的“本次执行范围”双选项，并动态显示各自可执行数量，同时明确：它不会修改列表勾选状态。

## 2. 新增任务检索

发送列表新增全文检索，覆盖：编号、Excel 行号、收件人、主题、正文、分类、附件名、定时时间和任务状态。多关键词采用 AND 逻辑。检索结果可直接作为本次执行范围。

## 3. 分类进一步统一

主 UI 不再并列“联系人分类 / 任务标签”。发送列表只保留一个“分类”列：
- 联系人系统分类：互动阶段 / 待跟进 / 发送策略
- 联系人长期自定义分类
- 当前任务自定义分类

底层仍保留来源，避免一次性任务分类污染联系人长期资料。旧 Excel 的“标签 / tag / tags”等列继续作为兼容别名读取，但 UI 统一称“分类”。

## 4. 定时时间前置显示

定时时间移动到分类之后，固定显示日期和时间，避免在宽表右侧被隐藏。未定时任务明确显示“未定时”。

## 5. 执行安全

“暂停 / 不再联系”继续由联系人发送策略硬拦截；批量仍只创建草稿，不自动发送。
