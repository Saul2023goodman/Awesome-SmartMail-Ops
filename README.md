# NetEase Mail Draft Assistant v0.1.0

一个面向 `mail.163.com` 的 Chrome MV3 测试插件。

当前只做一件事：

> 自动打开写信页，并填入收件人、主题、正文、附件和定时发送设置；不会自动发送邮件。

## 已实现

- 自动识别/打开“写信”页
- 自动填写收件人
- 自动填写主题
- 自动进入正文 iframe 并填写正文
- 从插件浮层选择本地附件，并自动注入网易邮箱附件输入控件
- 自动展开“更多发送选项”
- 自动启用“定时发送”
- 自动设置年 / 月 / 日 / 时 / 分
- 可选：自动点击“存草稿”
- 文本表单内容保存在 Chrome 本地存储中

## 安装

1. 解压本目录。
2. Chrome 打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择 `netease-mail-draft-assistant` 文件夹。
6. 打开网易邮箱网页版并登录。
7. 页面右下角会出现“草稿”按钮。

## 使用

1. 点击右下角“草稿”。
2. 填写收件人、主题、正文。
3. 如需附件，直接在浮层选择文件。
4. 如需定时，勾选“设置定时发送”并选择时间。
5. 点击“填入草稿”。
6. 插件会在网易写信页完成字段填入。

默认不会点击发送。

## 当前实现基于的网易页面规律

- Compose 容器优先按 `[role="main"][aria-label*="写信"]` 识别。
- 主题输入框使用动态 ID，但稳定后缀为 `_subjectInput`。
- 正文位于 Compose 编辑器内部 iframe 的 `body`。
- 附件 input 位于动态容器 `*_attachBrowser` 内。
- 定时字段使用稳定后缀：
  - `_scheduleYear`
  - `_scheduleMonth`
  - `_scheduleDay`
  - `_scheduleHour`
  - `_scheduleMinute`
- “更多发送选项”和“定时发送”优先按可访问语义/文字定位，而不是写死 `_mail_*` 动态 ID。

## 已知限制

### 1. 附件
浏览器安全模型禁止扩展凭一个本地路径字符串直接读取任意文件。因此 v0.1 的正确方式是：

- 用户在插件浮层中选择附件；
- 插件持有真实 `File` 对象；
- 再通过 `DataTransfer` 注入网易邮箱文件输入框。

这是浏览器安全限制，不是网易邮箱限制。

### 2. 收件人
当前根据已记录的网易行为执行 `value + input + change + blur`。后续版本应增加“收件人 token 已提交”的 DOM 后置验证。

### 3. 附件上传完成
当前每个附件注入后保守等待约 0.9 秒。大附件或慢网环境下，后续版本应增加网易附件上传状态检测，再允许自动存草稿。

### 4. 定时时间
如果网易分钟下拉框不包含用户指定分钟，插件会选择最接近的可用分钟，并在状态区提示。

## 安全说明

插件不读取 Cookie、密码或 Authorization Header，也不会自动点击“发送”。
