# NetEase Mail Draft Assistant v0.6.0

网易邮箱网页版外联工作台。插件只自动创建/填写草稿，不自动发送邮件。

## v0.6.0：桌面级工作台 UI

此前 v0.5 的功能已经超出右下角窄浮层适合承载的复杂度。v0.6 不再继续堆叠小面板，而重构为桌面级工作台：

- 右下角仅保留一个轻量启动按钮。
- 打开后默认使用约 1180px 宽、90vh 高的工作台。
- 左侧固定模块导航：单封草稿 / 批量任务 / 联系人。
- 中间为主工作区，表格、附件预检和联系人列表不再挤在窄面板内。
- 顶部提供“一键全屏 / 还原、收起、关闭”。
- 全屏模式使用浏览器可视区域，仅保留 12px 外边距。
- 小屏幕自动折叠左侧导航为图标栏。

### 单封草稿

采用“内容编辑区 + 右侧操作栏”布局：

- 左侧：收件人 / 主题 / 大尺寸正文编辑区。
- 右侧：附件、定时设置、自动存草稿、执行状态。

### 批量任务

按照真实工作流组织为五个阶段：

1. 导入任务表
2. 工作表与字段映射
3. 附件中心
4. 发送列表筛选/编辑
5. 顺序创建草稿

前三个准备阶段采用卡片式布局；发送列表独占大工作区，表格可视高度提升到约 430px；执行栏固定在工作区底部，批量运行时不用反复滚动寻找停止按钮。

### 联系人

联系人模块分为：

- 已发送同步
- 联系人操作
- 大尺寸联系人列表

联系人列表可搜索、按状态/标签筛选，并继续支持状态和长期标签编辑。

## 现有能力

- 单封草稿：收件人、主题、正文、附件、定时、存草稿。
- 批量导入：XLSX / CSV / TSV / JSON / TXT。
- 自动识别 Sheet、表头和字段，可人工修正映射。
- 公共附件、专属附件、附件目录扫描、缺失/歧义人工确认。
- 标签筛选：包含任一/全部、排除标签、批量加删标签、加入/排除发送。
- 读取网易“已发送”，维护联系人状态和标签。
- 批量任务采用单线程逐封新建 Compose，降低串稿风险。

## 安装

1. 解压 ZIP。
2. Chrome 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本目录。
6. 刷新已经登录的网易邮箱页面。
7. 点击右下角蓝色 `N` 启动工作台。

## 安全边界

- 插件不会自动点击最终“发送”。
- 联系人数据和表单状态保存在浏览器本机。
- 本地附件必须由用户通过文件/目录选择器明确授权。
- 批量执行中检测不到新的 Compose 实例时会停止，而不是覆盖上一封草稿。
