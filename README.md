# 网易邮箱草稿助手 v0.3.0

Chrome MV3 插件。单封/批量创建并保存网易邮箱草稿；不会自动发送邮件。

## v0.3.0：重构附件工作流

这一版把“附件文件池”改成更接近真实批量外联的 **附件中心**。

### 推荐使用方式

1. Excel/CSV 的“附件”列只写每封邮件的 **专属附件**，例如：
   - `导师A_ResearchProposal.pdf`
   - `材料/导师B_WritingSample.docx`
2. 同一批邮件都要附带的 CV、成绩单等，不需要在每一行重复写，直接在插件里选择为 **公共附件**。
3. 专属附件可以：
   - 一次多选全部文件（推荐，适合几十个附件）；或
   - 直接选择一个附件总目录（适合大量文件或分文件夹管理）。
4. 插件先完成全部附件匹配，再允许批量执行。

### 匹配优先级

从严格到宽松：

1. 相对路径精确匹配；
2. 选择文件夹时，自动忽略所选“总目录”这一层路径；
3. 文件名精确匹配；
4. Windows/Chrome 下载副本名兼容，例如表格写 `CV.pdf`，本地只有 `CV(1).pdf` 时可自动识别，并在预检中给出提示；
5. 仍无法确定时，显示“需要你确认的附件”，可直接从下拉框人工指定一次；同一附件引用在本批次后续任务中复用该选择。

不会在多个同名文件之间静默猜测。

### 公共 + 专属附件

每封最终附件 = `公共附件 + 当前行专属附件`，自动去重。

例如：

- 公共附件：`Junhao-Jiao-CV.pdf`
- Excel 第 1 行附件：`ResearchProposal_Professor_A.pdf`
- Excel 第 2 行附件：留空

则：

- 第 1 封：CV + Research Proposal
- 第 2 封：仅 CV

### 上传机制

v0.3.0 不再默认把多个附件逐个“伪选择”。

- 如果网易附件 input 支持 `multiple`，插件会把当前邮件的全部附件一次性交给网易控件，模拟用户在文件选择器中一次多选；
- 如果当前网易实例不支持多选，则自动回退到逐个上传；
- 每次上传后尝试从 Compose DOM 中确认附件文件名已经出现；如果页面没有暴露可确认的文件名，会在任务备注中记录“已提交但未在页面确认”，而不是伪称验证成功。

## 批量导入

支持：

- `.xlsx`
- `.csv`
- `.tsv`
- `.json`
- `.txt`

旧 `.xls` 请先另存为 `.xlsx` 或 CSV。

推荐字段：

| 编号 | 收件人 | 主题 | 正文 | 附件 | 定时时间 | 是否定时 |
|---|---|---|---|---|---|---|
| 001 | test@example.com | 测试主题 | 正文 | Proposal.pdf | 2026-08-25 09:30 | 是 |

## 安装

1. 解压 ZIP。
2. 打开 `chrome://extensions/`。
3. 开启开发者模式。
4. 点击“加载已解压的扩展程序”。
5. 选择 `netease-mail-draft-assistant-v0.3.0` 文件夹。
6. 刷新已登录的网易邮箱页面。
7. 右下角“草稿” → “批量”。

## 安全原则

- 不自动点击最终发送。
- 批量单线程逐封执行，降低串稿风险。
- 每封必须创建新的 Compose 实例。
- 缺失/歧义附件在预检阶段阻止对应任务执行，除非用户明确手动指定。
