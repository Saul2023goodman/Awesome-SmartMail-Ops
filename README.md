# NetEase Mail Draft Assistant v1.16.0

网易邮箱网页版草稿工作台。把一批邮件资料整理成可检查、可安排、可创建的网易草稿。只保存草稿，不自动发送。

## 现在怎么用

批量草稿只保留四个连续动作：

1. **添加资料**：选择文件、文件夹，或直接粘贴内容。
2. **检查邮件**：查看解析预览，只修改需要处理的邮件，也可以抽查全部邮件。
3. **选择与安排**：选择本次要创建的邮件；需要时展开自动安排时间。
4. **创建草稿**：确认选择后统一创建网易草稿。

一级工作区只保留：**批量草稿 / 单封草稿 / 联系人**。

## v1.16.0：性能重构

这一版重点处理界面切换、搜索、大批次列表和联系人页面的卡顿，不改变上述业务流程。

### 切换页面不再全量刷新

工作区切换只负责显示当前页面。只有数据实际变化时才标记页面需要更新，并在页面真正可见时合并到下一帧渲染。隐藏的批量页或联系人页不会提前创建大量 DOM。

### 减少重复渲染

- 批量搜索和联系人筛选增加短防抖，连续输入只触发一次最终刷新。
- 单封草稿输入改为延迟保存，避免每敲一个字符都写浏览器存储。
- 批量列表和联系人列表使用事件委托，不再为每一行重复创建事件监听器。
- 普通勾选、状态更新、执行进度只刷新必要区域；附件、名单核对、解析概况等只在结构变化后重算。

### 大数据量处理

- 联系人按 250 条分段显示，避免一次生成上千行。
- 解析预览队列同样按 250 条分段显示。
- 总名单核对先建立邮箱/姓名索引，再批量匹配，避免每封邮件都完整扫描一次名单。
- 邮件搜索预先缓存不常变化的文本，联系人阶段/标签等派生结果也按版本复用。
- 附件上传后的页面证据每轮只扫描一次，不再对每个附件重复遍历 Compose DOM。
- 定时草稿成功页的宽范围兼容扫描降低频率，避免等待保存结果时反复扫描网易的大型页面 DOM。

### 降低绘制成本

- 去掉固定标题、流程栏和解析区上的实时背景模糊。
- 对工作台、表格和离屏卡片增加布局/绘制隔离；屏幕外内容接近视口前不参与完整渲染。
- 最终创建区仍保持普通文档流，不增加第二个固定悬浮层。

## v1.15.0：操作流重构

- “逐条确认”回到批量流程，作为解析预览，不再是独立工作区。
- 批量填写只在选中邮件后出现，不独立占区域。
- 选择邮件与安排时间合并。
- 邮件列表减少不必要列，低频功能默认收起。

## 联系人

联系人页面负责联系记录与邮箱同步。日常主操作只保留“同步邮箱”；重建记录等维护操作放在折叠选项中。

## 安全边界

- 只创建并保存草稿，不自动发送。
- 每封草稿确认保存成功后才继续下一封。
- 批量执行遇到错误立即停止，避免串稿。
