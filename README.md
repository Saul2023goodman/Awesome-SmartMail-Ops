# NetEase Mail Draft Assistant v1.14.0

网易邮箱网页版外联工作台。只创建并确认保存草稿，不自动发送。

## v1.14.0：独立确认工作区 + 右侧固定流程

本版继续按真实业务流程收敛界面。核心变化不是增加更多按钮，而是重新定义“逐条确认”的产品角色：它不是导入后的附属异常框，而是批量外联进入执行前的独立质量门。

## 一级工作区

1. **批量工作台**：添加资料、选择本批次任务、安排时间、创建草稿。
2. **逐条确认**：集中核验、修正和放行邮件；系统自动复核后，人工处理剩余不确定项，也可主动抽查全部邮件。
3. **单封草稿**：处理不属于批次的临时单封邮件。
4. **联系人**：长期联系状态、跟进记录与邮箱同步。

“逐条确认”独立后，用户不会再把质量核验误认为一次性的导入步骤；它可以随时返回，并持续显示待确认数量。

## 批量业务流程

右侧固定流程栏统一显示五个业务阶段：

1. **添加资料**：文件、文件夹或粘贴内容；可选总套磁名单。
2. **逐条确认**：机器先复核；人工处理缺失、冲突和歧义，也可以主动检查全部邮件。
3. **选择任务**：决定本批次真正要创建哪些邮件。
4. **安排时间**：可选；按学校规则自动排程，并保留已有时间。
5. **创建草稿**：逐封写入网易写信页，确认“存草稿”成功后才继续。

流程栏采用右侧 `sticky` 竖列，而不是页面顶部横条。用户滚动长工作台时仍能看到当前位置、前后阶段与状态；同时不占用正文纵向空间，也避免为了切换阶段反复滚回顶部。

## 逐条确认：独立质量门

### 待确认 / 全部邮件

- **待确认**：只显示机器无法可靠判定的邮件。
- **全部邮件**：允许主动抽查自动通过项。
- 左侧队列负责选择对象，中间查看来源证据，右侧修改最终邮件。

### 批量处理

批量动作只在用户选中邮件后出现：

- **批量补主题**：只填充所选邮件中的空白主题，不覆盖已有主题。
- **保存并确认所选**：批量保存并放行核心字段完整的邮件；收件人、主题或正文仍不完整的项目继续留在待确认队列。
- **清除选择**：退出本次批量处理。

这使重复性修正可以一次完成，同时保留逐封检查能力和质量门约束。

## 进一步减少重复

- 原批量工作台里的“抽查邮件表”退出主流程；确认与抽查统一进入“逐条确认”。
- 原“确认准备完成”改为更准确的 **进入任务选择**，只承担阶段推进，不制造第二次“确认”概念。
- ZIP 已属于“选择文件”能力，不再提供独立同权入口。
- 联系人日常主操作只保留“同步邮箱”；“重建联系人记录”继续放在维护选项中。
- 字段映射、来源结构等高级能力继续按需展开。

## 安全边界

- 只创建并确认保存草稿，不自动发送。
- 批量执行遇到错误立即停止，避免串稿。
- 附件、定时、联系人拦截和原有识别/校验逻辑保留。
