# NetEase Mail Draft Assistant v1.19.0

网易邮箱网页版草稿辅助插件。主流程：**添加资料 → 检查邮件 → 选择与安排 → 创建草稿**。插件只创建/保存草稿，不自动发送。

## v1.19.0

这一版重点解决“事情已经完成，但界面仍要求再确认/再进入下一步”的重复操作。

- **确定性问题补齐即通过**：缺收件人、主题或正文时，补齐并通过字段验证后自动移出待处理。
- **一键主题不再要求全选确认**：填写同一主题后，每封邮件按当前事实重新判断；只缺主题的自动完成，真正有解析歧义的才继续待处理。
- **识别状态会随当前内容更新**：缺 Subject 等原因导致的旧低置信度不会在用户补齐主题后继续作为历史阻塞。
- **最后一个待办完成后自动推进**：有下一封就自动打开；缺附件就自动去附件区；全部完成就自动进入“选择与安排”。
- **干净批次直接进入下一步**：导入后没有阻塞时，无需再点“继续选择邮件”。
- **邮件内容成为检查区主视图**：收件人、主题、正文位于主要编辑区域；正文提供更大的完整编辑空间。
- **原文降级为“解析依据”**：默认按需展开，展示识别步骤、置信度、候选邮箱与原始块边界；只有存在真实解析歧义时自动展开。
- **批量确认只服务真正的人工判断**：缺字段邮件不再出现无意义的批量确认选择。
- **自动安排时间继续默认展开**：进入“选择与安排”后直接可用。

详细逻辑见 `UX-FLOW-v1.19.md`。

## 主要文件

- `content.js`：工作台、业务状态、自动推进与网易邮箱交互
- `content.css`：工作台样式与响应式布局
- `mail-recognizer.js` / `importer.js`：邮件识别与导入
- `scheduler.js`：自动排程
- `contacts.js`：联系人状态
- `UX-FLOW-v1.19.md`：本轮自动推进与编辑优先说明
- `BUSINESS-STATE-v1.18.md`：问题分类与状态路由基础
- `PERFORMANCE-REFACTOR.md`：性能优化说明

## 安装

1. 解压插件目录。
2. Chrome/Edge 打开扩展管理页并启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向该目录。
4. 打开网易邮箱网页版使用。
