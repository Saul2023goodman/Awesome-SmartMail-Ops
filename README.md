# NetEase Mail Draft Assistant v1.18.0

网易邮箱网页版草稿辅助插件。主流程保持为：**添加资料 → 检查邮件 → 选择与安排 → 创建草稿**。插件只创建/保存草稿，不自动发送。

## v1.18.0：按“未解决事项”驱动状态

这一版修正了一个核心业务逻辑：邮件是否处于“待处理”，应该由**当前还剩什么问题**决定，而不是由“它曾经进入过待处理”决定。

- **缺主题补齐后自动通过**：如果一封邮件进入待处理的唯一原因是缺少主题，填写主题后立即移出待处理，不再额外要求一次“确认”。
- **一键补主题会自动清理状态**：批量补齐空白主题后，只剩主题问题的邮件自动变为可用；仍缺收件人、正文或存在解析歧义的邮件继续留在待处理。
- **确定性问题与人工判断分开**：缺收件人、无效邮箱、缺主题、缺正文等可验证问题，在修复后自动解除；低置信度、边界不清、名单冲突、对已完整邮件的人工改写仍需要明确确认。
- **附件成为独立待办**：资料中明确要求附件但本地没有对应文件时，不再归入“其他问题”，而是显示“附件待加”，并首次自动展开附件区域，直接列出缺少的文件。
- **附件补齐后自动解除阻塞**：选择文件/文件夹后重新匹配，匹配成功的附件问题自动消失，无需再确认。
- **无法识别的导入时间不再制造死路**：原时间无法识别时保留提示，但不阻塞当前步骤；进入默认展开的“自动安排时间”后重新选择即可。
- **联系限制不阻塞整批**：标记为“不再联系”的联系人自动停止创建该封邮件，但不会让其他正常邮件无法继续。
- **界面汇总按动作分类**：解析结果改为“内容待补 / 需要核对 / 附件待加 / 其他阻塞”，只显示当前存在的类别，不再把不同问题塞进“其他问题”。

## 业务状态原则

1. **状态由当前事实推导，不保存历史标签。** 问题解决后，状态立即随之变化。
2. **谁能解决问题，问题就出现在哪一步。** 内容问题在邮件检查中处理；附件问题回到资料区；时间问题交给排程；联系限制直接停止对应任务。
3. **确定性修复自动通过，主观判断才需要确认。** 减少没有信息价值的重复点击。
4. **批量动作不能制造新的待确认。** 一键补主题只改变空白主题，且自动重新计算每封邮件的剩余问题。
5. **不能在下一步才能修的问题阻塞上一步。** 导入时间无法识别时，允许进入排程阶段重新安排。

## 文件

- `content.js`：工作台、业务状态与网易邮箱交互
- `content.css`：工作台样式与响应式布局
- `importer.js` / `import-core.js` / `mail-recognizer.js`：导入与解析
- `scheduler.js`：自动排程
- `contacts.js`：联系人状态
- `PERFORMANCE-REFACTOR.md`：v1.16 性能结构说明
- `UX-REFACTOR-v1.17.md`：v1.17 阅读与顺势操作说明
- `BUSINESS-STATE-v1.18.md`：本轮状态机与问题路由说明

## 安装

1. 解压插件目录。
2. Chrome/Edge 打开扩展管理页并启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向该目录。
4. 打开网易邮箱网页版使用。
