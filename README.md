# NetEase Mail Draft Assistant v1.12.0

网易邮箱网页版外联工作台。只创建并确认保存草稿，不自动发送。

## v1.12.0：流程化产品界面

本版重点不是增加功能，而是把已有能力重新组织成普通用户能直接理解的业务流程：

**添加资料 → 核对邮件 → 选择与定时 → 创建草稿**

### 主要变化

- 导入页与批量页顶部使用同一条四步流程指引，并根据当前批次状态自动显示完成、当前、未开放状态。
- 流程步骤可点击跳转；尚未完成邮件核对时，后续步骤会明确锁定。
- 左侧模块改为“导入与核对 / 批量创建”，减少“导入、批量、执行”等工程式分区感。
- 删除默认界面中的 Adapter、识别器、邮件帧、置信度、证据分、快照、增量、原子替换等技术说明。
- 默认界面只保留业务结果：找到多少邮件、多少可直接使用、多少需要确认、是否存在阻塞问题。
- 人工处理中心改为“待处理 / 原文 / 修改邮件”三栏，用原文辅助判断，不要求用户理解识别算法。
- “高级映射”改为折叠的“导入设置”，只有自动结果明显不对时才需要打开。
- 附件、总名单核对、排程、联系人读取说明统一改为面向任务的短文案。
- 联系人页移除“证据层 / 决策层”技术示意，保留“快速刷新 / 完整重建”两个明确动作。
- 批量页将“智能排程”改为“安排时间”，默认规则直接表达为“同校每 7 天 1 位”。
- 工作台略微加宽，并提高主要标题、流程和操作区域的视觉层级，降低说明文字密度。

## 批量业务流程

1. **添加资料**：文件、文件夹、ZIP 或粘贴内容；总套磁名单为可选参考资料。
2. **核对邮件**：系统整理邮件，只把缺失或冲突项目交给用户；支持批量补缺失主题。
3. **选择与定时**：完成导入后进入任务列表，勾选本次要创建的邮件，可按学校规则安排时间。
4. **创建草稿**：只执行已勾选且可创建的任务；每封均点击网易“存草稿”并确认成功后才继续下一封。

联系人为长期工作区，不属于一次批次的必经步骤。
