# NetEase Mail Draft Assistant v0.5.0

Chrome MV3 扩展，用于网易邮箱网页版的单封/批量草稿、附件匹配、定时草稿、已发送读取、联系人状态和标签化发送列表管理。插件不会自动点击最终发送。

## v0.5.0：标签化发送列表

### 标签来源

标签有两类，批量列表会自动合并为“有效标签”：

1. **任务标签**：来自导入表的 `标签 / 批次 / 分组 / 类别 / 分类 / tag / tags` 等列，也可在当前批次中手工修改。
2. **联系人标签**：保存在联系人状态库中，可以跨不同批次、不同导入文件长期复用。

例如一条任务本身有 `第一批;心理学`，联系人长期标签为 `重点;北师大`，则该任务的有效标签是：

`第一批 / 心理学 / 重点 / 北师大`

### 根据标签筛选

批量页“4. 筛选与编辑发送列表”支持：

- 包含标签；
- “包含任一”或“同时包含全部”；
- 排除标签；
- 点击标签 chips 快速加入/移出筛选；
- 标签筛选条件保存在本机 Chrome，下次打开继续使用。

### 编辑筛选后的发送列表

筛选后可以一次对当前结果：

- 加标签；
- 移除标签；
- 加入发送；
- 排除发送。

每一行也有：

- “发送”勾选框；
- 当前任务标签输入框。

“排除发送”不是视觉隐藏：真正执行批量建草稿时会跳过这些任务。

### 执行范围

开始批量建草稿前可选择：

- **全部“纳入发送”的任务**；
- **仅当前标签筛选结果中“纳入发送”的任务**。

因此可以在一份大名单里依次运行不同子批次，不必反复拆 Excel。

示例：

- 今天筛选 `第一批 + 北京`，只运行当前筛选；
- 下一次筛选 `第二批`，继续建立另一批草稿。

### 联系人标签

联系人页新增标签列，可直接编辑多个标签，使用分号或逗号分隔。联系人页也可按标签筛选。

“同步当前批量名单/标签”会将当前任务中的标签追加到对应联系人档案中，不会删除联系人已有标签。

### 导入字段

推荐列：

`编号 | 收件人 | 主题 | 正文 | 附件 | 定时时间 | 是否定时 | 标签`

标签可写：

`第一批;重点;心理学`

支持同义表头包括：标签、邮件标签、联系人标签、任务标签、批次、分组、类别、分类、tag、tags、label、labels、group、batch、category。

## 既有功能

- 单封草稿自动填写；
- XLSX / CSV / TSV / JSON 导入；
- 自动工作表与字段识别；
- 公共附件 + 专属附件 + 目录扫描 + 人工纠错；
- 网易 Compose iframe 正文写入；
- 定时年月日时分设置；
- 顺序创建草稿、防串稿；
- 读取网易已发送邮件；
- 联系人状态：未联系 / 已发送 / 已回复 / 待跟进 / 暂停 / 不再联系；
- 联系人 CSV 导出；
- 每个网易邮箱账号使用独立联系人状态库。

## 安装

1. 解压 ZIP。
2. 打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择 `netease-mail-draft-assistant-v0.5.0` 文件夹。
6. 刷新已登录的 `mail.163.com` 页面。

## 安全边界

- 本扩展不会自动点击最终发送。
- 本地选择的附件 File 对象只存在于当前页面会话，刷新后需重新选择。
- 联系人状态/标签保存在 `chrome.storage.local`，按当前邮箱账号隔离。
- 标签筛选不会默默删除任务；任务是否真正执行由“发送”勾选状态和执行范围共同决定。
